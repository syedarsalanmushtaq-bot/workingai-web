# Write Plain

A Working AI writing skill for clear thought, precise words and natural sentences. Preserve meaning before brevity.

## Use it in a chat

Copy the full SKILL.md text into your AI conversation. Add the text to rewrite and say: "Use Write Plain to rewrite the text below. Preserve its meaning and return only the finished text."

For an explanation, ask: "Use Write Plain to explain [topic] for [reader]."

## Use it as a saved skill

Extract the write-plain folder. Add it to the skills location supported by your AI tool, keeping SKILL.md inside that folder. Follow your tool's own instructions for loading skills. Then ask it to use Write Plain.

Review the result against the original. Check the intended action, certainty, obligation, timing and scope. A style instruction cannot guarantee accuracy.
